# wffp — personal portfolio

Static single-page portfolio of **Rattry Wu** (@Xarfa). Deployed via GitHub Pages at
`https://xarfa.github.io/wffp/` once Pages is enabled on this repo.

- `index.html` + `style.css` — hand-written, no framework, no build step.
- `assets/` — images shared with the pen repository. **Placeholder renders** (`hero.png`,
  `exploded.png`, `detail-nib.png`, `flatlay.png`) are swapped by overwriting the file with
  the same name — no code changes needed. Sizes are annotated inside each placeholder.
- The star-history chart lives in the pen repository's README (auto-updated weekly there by
  a GitHub Action); the site links to the repo instead of duplicating the chart.
